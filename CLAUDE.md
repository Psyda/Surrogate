# Surrogate

Fabric mod for Minecraft 1.21.1. See README.md for the game loop and docs/ for design.

## Writing rule (read this first)

Every player-facing word and every design doc follows docs/WRITING.md. The short version:
no semicolons, no em-dashes or en-dashes anywhere, one idea per sentence, gameplay lines
under fifteen words, contractions are normal, name the object and the verb in every
instruction. Read docs/WRITING.md before writing or editing any dialogue, lang entry,
terminal text, book, or design note.
